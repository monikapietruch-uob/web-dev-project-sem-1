# Page to Portfolio

Web dev project, semester 1. Small web development tasks for foundation students at the University of Bedfordshire. It is not an official page of the university.

## What it is

A website with short tasks that students do at home, about 15 minutes at a time. They revise HTML and CSS, put a page online with GitHub, meet VS Code, build one website together as a team, turn it into their own portfolio, keep notes in Notion, practise the English of tech, and plan what to learn next. Nothing needs installing.

## Who it is for

Students on the foundation tech pathways (electronic engineering, computer science and cyber security), and their teachers.

## The seven lines on the map

| Line | What students do |
|---|---|
| 01 Solo | Revise HTML and CSS, start using GitHub and VS Code, learn to commit and push, study real portfolios, set up LinkedIn, write a few buttons and a form in JavaScript |
| 02 Team | Build the website Class of 2026 together: issues, a project board, pull requests, reviews, a user test and a retrospective |
| 03 Make it yours | Fork the team website and turn it into the start of a portfolio |
| 04 Notes | Keep notes in Notion and copy the study hub template |
| 05 What next | Free courses, useful communities, AI as a study partner, a CV and interview practice, a plan for semester 2 |
| 06 Language lab | Say code aloud, read documentation, write commit messages, a summary and an argument, plan a short reflective talk |
| 07 Pathways | Three tasks each for electronic engineering, cyber security and computer science |

At the moment only the Solo line is open. The other six lines show their path, and they unlock later.

Every stage ends with a short checkpoint quiz. The Toolbox has a page for when something does not work, word practice, a typing gym for symbols, cheat sheets to print, a record of progress that can be saved to a file, and display settings.

## How it is built

Plain HTML, CSS and JavaScript. No framework and no build step. Open `index.html` in a browser to run it.

| File or folder | What it holds |
|---|---|
| `index.html` | All the pages and tasks. Each part starts with a large comment. |
| `css/` | The look, in thirteen small files. `base.css` has the colours and the fonts. |
| `js/` | The code, in fifteen small files. `index.html` loads them in order. |
| `puzzles/` | The practice page for the task "Find the flag". It is a small website of its own. |
| `404.html` | The page for an address that does not exist. |

Every file starts with a comment that says what it is for.

Progress and notes are saved in each student's own browser. Nothing is sent anywhere.
