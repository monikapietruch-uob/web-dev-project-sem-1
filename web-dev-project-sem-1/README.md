# Page to Portfolio

Web dev project, semester 1. Small web development tasks for foundation students at the University of Bedfordshire. It is not an official page of the university.

## What it is

A website with short tasks that students do at home, about 15 minutes at a time. They revise HTML and CSS, put a page online with GitHub, build one website together as a team, keep notes in Notion and plan what to learn next. Nothing needs installing.

## Who it is for

Students on the foundation tech pathways (electronic engineering, computer science and cyber security), and their teachers.

## The five tracks

| Track | What students do |
|---|---|
| 01 Solo | Revise HTML and CSS, start using GitHub, study real portfolios, set up LinkedIn, write one button in JavaScript |
| 02 Team | Build the website Class of 2026 together: issues, a project board, pull requests, reviews |
| 03 Make it yours | Opens later: fork the team website and turn it into the start of a portfolio |
| 04 Notes | Keep notes in Notion and copy the study hub template |
| 05 What next | Free courses, useful communities, AI as a study partner, a plan for semester 2 |

## How it is built

Plain HTML, CSS and JavaScript. No framework and no build step. Open `index.html` in a browser to run it.

| File or folder | What it holds |
|---|---|
| `index.html` | All the pages and tasks. Each part starts with a large comment. |
| `css/` | The look, in nine small files. `base.css` has the colours and the fonts. |
| `js/` | The code, in nine small files. `index.html` loads them in order. |
| `404.html` | The page for an address that does not exist. |

The page "How the code works" explains every file. Open the site and click "Tutor notes" at the bottom of any page.

Progress and notes are saved in each student's own browser. Nothing is sent anywhere.
